Verifica

"Verifica" é o nome de uma ferramenta open-source usada para corrigir automaticamente atividades feitas em python com base em um arquivo de correção. Todas as atividades desse site possuem integração com essa ferramenta. Isso significa que todas as atividades que você fizer por esse site podem ser corrigidas automaticamente na sua própria máquina, recebendo um feedback instantâneo.

Você pode instalar o pacote através do pip usando o seguinte comando no Windows:

pip install verifica

O comando em linux depende da distro e das configurações de instalação do python, mas é basicamente da mesma forma que você instala qualqer outro pacote na sua máquina.

Agora com o pacote instalado, para corrigir qualquer código basta estar na mesma pasta que ele e usar o comando informado no final da descrição da atividade.

Observações importantes

  • Siga as instruções a risca. Nomes de arquivos devem permanecer iguais aos informados na atividade.
  • Se você adicionar a pasta de script Python ao Path você pode usar o comando como verifica ... ao invés de python -m verifica ...
  • Se encontrar algum bug ou ter alguma sugestão para a ferramenta, acesse o github e crie um issue!
